- Updates: initial check after one minute, then every four hours; download is not automatic and install-on-quit is enabled. Source: main:5997-6021 and 6882-7124.

OBSERVED ABSENCE — job-application product functions
The complete first-party route, preload capability, API endpoint, service-constructor, and storage-namespace inventory contains no implementation for:
- job discovery, ranking, freshness, deduplication, or career-track agents;
- local/cloud application browser runners or multi-account browser profiles;
- job-specific resume tailoring, visible resume diff, or PDF/DOCX export;
- reusable application-answer memory;
- ATS adapters or generic application-form fallback;
- CAPTCHA, 2FA, assessment, or application-browser takeover;
- application queues, leases, idempotency, crash recovery, duplicate-submit prevention, or submission receipts;
- application confirmation screenshots/evidence trails;
- Gmail/Outlook/calendar outcome tracking.

These are evidence-backed absences from this desktop artifact, not statements about other Final Round web products.
