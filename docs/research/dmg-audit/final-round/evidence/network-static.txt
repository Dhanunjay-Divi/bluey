OBSERVED — authentication and transport
- HTTP requests acquire a valid access token and send it as Authorization bearer. Source: main HTTP client/auth provider around 5315-5560.
- Socket connects with WebSocket transport only; JWT is sent in socket auth field `session`, with application/device headers. Source: main:5562-5644.
- Socket reconnect budget is ten attempts in the client config path, with exponential jitter approximately 1-10 seconds; user retry resets the counter. Source: main:5657-5915.
- Runtime schema validation logs mismatches but invokes handlers anyway. Source: main:5731-5753.
- HTTP wrapper defaults to zero retries; call timeouts observed range from ten to thirty seconds. Source: HTTP client and service configurations.

OBSERVED — device/fingerprint data
- Persistent encrypted random device ID plus platform, OS version, app version/build/name/distribution, timezone, screen resolution, and macOS model (`sysctl hw.model`) are added to requests. Source: main:11280-11409.
- Payment checkout can emit a Corgi browser-fingerprint event for fraud/risk use. Source: main:12683-12699.

OBSERVED — telemetry
- Sentry initializes with logs enabled, production trace sample rate 0.5, and error sample rate 1.0. Source: main:6409-6456.
- PostHog and Amplitude initialize in main and identify authenticated users with user ID, email, and name. Source: main:7897 onward, 10489-10501, and 21458-21469.
- App logger disables its local file transport, sanitizes structured keys, and forwards structured log attributes to Sentry. Source: main:5100-5194.
- The sensitive-key list covers credential/session/PII key names but does not cover a generic `text` key. Source: main:3765-3805.
- Live transcript-final logging includes an 80-character `text` prefix, and assistant-final logging passes complete answer text under `text`; both flow through the Sentry-forwarded logger. Source: main:12104-12115 and 12251-12255.

INFERENCE
- Interview content can enter remote Sentry logging because the static call path forwards those unredacted `text` attributes. The bounded runtime produced a local Sentry queue but outbound traffic was blocked, so actual production delivery was not observed.
