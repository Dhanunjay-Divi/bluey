What changed — the whole UX, not a recolor

Three calm states — pill (idle), Ask bar (fast path), full panel. Was: one cluttered panel for everything.
Ask bar = Spotlight — ⌥Space → type → answer floats in → tucks away. The 90% case, zero chrome.
Segmented panel — Ask · History · Agents. Was: overlapping drawers + a faded tab strip bolted on.
History at scale — search + date groups + pins + show-more. Was: flat list capped at 8, no search.
One “+” menu — screen / attach / recap / capture tucked away. Was: a six-button footer row.
Killed the clutter — no Docs-empty badge, no captions strip jammed mid-panel, no opacity slider on the face.
Real frosted glass — backdrop-filter: blur saturate, you see the desktop through it. Was: a near-opaque black box.
Dashboard-exact tokens — #3B82F6 accent, white-alpha text, hairlines, SF type. No neon cyan, no glow.

All 54 existing features still live here — answers, 9 card kinds, fix-proposals, canvas, sessions CRUD, agents + connectors, billing-disclosure modal, knowledge/attach, recording, screen capture, recap — just reorganized into this calm structure instead of crammed onto one face. The pill keeps its 5 run-states; nothing is dropped.
