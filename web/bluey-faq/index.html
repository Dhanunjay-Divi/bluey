What is Bluey?

Bluey is a private desktop AI copilot for live technical work. It answers from user-approved meeting, screen, file, code, document, and saved project context.

What does Bluey do better than a normal chatbot?

Bluey keeps the current work context attached. Instead of copying meeting notes, screenshots, docs, and code into a separate chat, you can ask from the context already available in the session.

Can Bluey answer coding and design review questions?

Yes. Bluey can use code snippets, design review context, requirements, visible screen text, and saved project notes to produce a grounded recommendation.

What happens if Bluey does not have enough context?

It should say what is missing and ask for the right source, such as a screenshot, document, repository snippet, prior session, or external source.

Does Bluey use web search?

When web context is available, Bluey keeps it separate from local context, shows sources where possible, and follows your account settings.

How does balance work?

You can start free, then add account balance. Balance is shared across your Bluey sign-ins and is used for paid AI models, speech transcription, screen analysis, saved-session search, and related cloud work.
