What saved context is for

Follow-up continuity

Make "what about the last option?" answerable because prior context is still available.

Project recall

Bring decisions, constraints, docs, and issue context back into current work.

Cross-device restore

Cloud-synced sessions can restore approved context on another signed-in device.

Privacy stance

Saved session memory should be account-scoped, exportable, deletable, and clearly separated from local-only context. Bluey should not store more than it needs to restore and answer from approved sessions.
