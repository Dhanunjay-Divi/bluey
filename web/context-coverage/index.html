Context coverage

Good answers start with honest context.

Bluey is designed to answer from the sources it actually has: transcript, screen, files, docs, code, saved memory, and managed sources. When evidence is missing, the answer should say so and ask for the right next input.

No source? Say what is missing.

What Bluey can use

Current session

Prompt, transcript snippets, recent answers, and follow-up state from the active session.

Attached evidence

Files, docs, screenshots, screen analysis, code, and selected context the user provides.

Saved memory

Account-scoped saved sessions, summaries, decisions, and searchable project context.

What Bluey should not pretend

  • That it saw an unattached document or hidden screen.
  • That stale information is current without a managed source check.
  • That a repeated answer is new evidence.
  • That a missing source can be replaced with confidence.
For fresh facts, prices, product changes, schedules, or public claims, Bluey needs a managed retrieval lane with citations or the user should attach a reliable source.
