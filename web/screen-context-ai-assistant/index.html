Screen context

Ask about what is on your screen, with the rest of your work attached.

When enabled by the user, Bluey can analyze screen context and combine it with live transcript, docs, files, code, and memory. That makes it useful for debugging, review, research, and explaining what is visible.

Where screen context helps

Debugging

Use visible logs, errors, charts, consoles, or dashboards as part of the answer.

Meetings

Connect what someone is sharing with the current conversation and saved context.

Documents

Ask about a visible doc, form, spreadsheet, or code review without retyping every detail.

Consent and control

Screen analysis should be user-controlled and limited to context the user is authorized to process. Bluey should label screen-derived context separately from transcripts, docs, saved memory, and web sources.
