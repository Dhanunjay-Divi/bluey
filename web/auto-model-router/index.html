Routing signals

Quick

Short answers that rely on current conversation or known context.

Coding

Requests that need code, tests, diffs, or implementation reasoning.

Screen

Questions that depend on what is visible in the current workspace.

Research

Questions that need external sources, citations, freshness, or verification.

Why routing matters

Routing keeps latency, balance use, and answer quality balanced. Quick text asks can be light; audio, screen, files, research, and deeper reasoning can use more. The overlay can stay compact while details open for fuller organized answers when the task is complex.
