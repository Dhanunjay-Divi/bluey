Overlay principles

Visible controls

Listening, screen context, attachments, and answering should be tied to controls the user can see and understand.

Small when idle

The app can collapse to a compact pill and expand when the user needs the full session surface.

Clear source labels

Answers should make it clear whether they used transcript, screen, files, memory, or managed sources.

Bluey is for authorized work context. Capture-exclusion behavior depends on operating system support and should not be treated as a security boundary.
